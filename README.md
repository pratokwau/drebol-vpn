# Drebol VPN Bot

Telegram-бот для продажи VPN-подписок. Выдаёт подписки через панель
Remnawave, принимает оплату через Platega, а пользователям даёт личный
кабинет (Telegram Mini App) и сайт.

## Что умеет бот

### Для пользователей

- **Платные подписки**: тарифы на выбор, пробный период, продление,
  напоминания о скором истечении.
- **Промокоды** и **реферальная программа**: пригласил друга — получил бонус.
- **Устройства**: ограничение по количеству устройств (HWID), докупка мест.
- **Подключение в одно нажатие**: Happ и INCY, ссылка подписки с копированием.
- **LTE-интернет**: отдельные LTE-серверы для периодов, когда в регионе
  включают ограничения интернета. В кабинете и на `/start` виден остаток
  LTE-трафика на текущий месяц; при исчерпании лимита подписка
  автоматически переключается на fallback-сквад, а в новом месяце
  возвращается обратно.
- **Поддержка**: обращения в бот с файлами, ответы приходят сюда же.
- **Личный кабинет**: срок, трафик, LTE, устройства, платежи, рефералка,
  перевыпуск ключа и продление с оплатой — не выходя из Mini App.

### Для администратора (`/admin`)

- **📊 Статистика** и **💰 Оплаты**: список платежей, полная и частичная
  отмена через Platega (частичный возврат не меняет срок подписки).
- **💳 Платные подписки** и **📋 Админские**: выдача, продление, лимиты,
  сквады Remnawave, LTE-настройки (лимит в ГБ, LTE-сквад, fallback-сквад).
- **🛰 Контроль**: кто онлайн, трафик по нодам и периодам, ежедневная
  сводка с бэкапом.
- **🎫 Тикеты** и **📣 Рассылка**, **👥 Помощники** с разграничением прав,
  **📢 Канал** (в т.ч. обязательная подписка).
- **🎯 Возврат ушедших**: автоматические промокоды после истечения подписки.
- **⛔ Чёрный список**: общий список + второй источник (ban-vpn), ручные
  записи, исключения. Подписка человека из списка останавливается сама,
  а оставшийся срок сохраняется и возвращается, когда человек выходит
  из списка. Отдельного бана в боте нет — только чёрный список.
- **🕵 Повторные триалы**: защита от повторного получения пробного периода.
- **🖥 Панель и узлы**: узлы и сквады Remnawave, синхронизация
  (панель → бот, актуализация юзернеймов и ников через живой Telegram,
  сверка платежей) — точечно и по расписанию.
- **🌐 Сайт** и **🪪 Личный кабинет**: лендинг и Mini App разворачиваются
  из админки на свой сервер по SSH (nginx + certbot).
- **💾 Бэкап и перенос**: архив базы, конфига и ассетов — в один файл.
- **📄 Документы**, **💬 Поддержка**, **🧾 Лог-канал**, **🛠 Техработы**,
  **🔄 Обновиться с GitHub**.

## Оплата без вебхуков

Вебхуки Platega не используются сознательно: бот сам опрашивает статусы
незакрытых счетов раз в минуту (`invoice_poll_seconds`, по умолчанию 60)
и засчитывает оплату — продлевает срок и начисляет устройства. Поэтому
в личном кабинете Platega поле Callback URL остаётся пустым: для
продления из кабинета оно не нужно. После оплаты Platega возвращает
человека обратно в кабинет, на вкладку платежей.

## Установка на Ubuntu-сервер

Одна команда — скачает, установит и запустит бота с автостартом:

```bash
curl -fsSL https://raw.githubusercontent.com/pratokwau/drebol-vpn/main/install.sh | sudo bash
```

Скрипт спросит токен бота и Telegram ID администратора при первой
установке, а затем:

- установит `git`, `python3`, `pip`, `venv`;
- клонирует репозиторий в `/root/drebol-vpn`;
- создаст виртуальное окружение и поставит зависимости;
- создаст `systemd`-сервис `drebol-vpn` с автозапуском при перезагрузке
  и падении, плюс сторожа `scripts/notify_failure.sh`, который сообщит
  в Telegram, если бот упадёт.

Ручная установка — то же самое без `curl`:

```bash
git clone https://github.com/pratokwau/drebol-vpn.git
cd drebol-vpn
sudo bash install.sh
```

## Управление

```bash
systemctl status drebol-vpn    # статус
journalctl -u drebol-vpn -f    # логи в реальном времени
systemctl restart drebol-vpn   # перезапуск
systemctl stop drebol-vpn      # остановка
```

## Обновление

Проще всего — кнопка **«🔄 Обновиться с GitHub»** в админке. Вручную:

```bash
cd /root/drebol-vpn
git pull
systemctl restart drebol-vpn
```

Если менялся кабинет или сайт, после перезапуска нужно ещё
**развернуть сайт заново** из админки бота — иначе новая версия
кабинета на сайт не попадёт.

## Конфигурация

Токен и ID администратора хранятся в `/root/drebol-vpn/.env`:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_ID=ваш_telegram_id
```

Всё остальное — тарифы, промокоды, узлы, сайт, кабинет — настраивается
в самой админке бота и хранится в `/root/drebol-vpn/config.json`,
а данные — в SQLite-базе `/root/drebol-vpn/bot.db`.

Параметры API кабинета: `webapi_enabled`, `webapi_port` (по умолчанию
8088), `webapi_public` — адрес, по которому сайт проксирует `/api/`
в бот. Вход в кабинет — через Telegram Login Widget на сайте или
initData внутри Mini App, сессия живёт 7 дней.

## Запуск вручную (для разработки)

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

Зависимости (`requirements.txt`): `python-telegram-bot[job-queue]`,
`aiosqlite`, `aiohttp`, `python-dotenv`, `qrcode`, `paramiko`.

## Структура проекта

```
drebol-vpn/
├── bot.py            # Точка входа: polling, задачи по расписанию
├── config.py         # .env + config.json
├── database.py       # SQLite (bot.db): подписки, платежи, ЧС, сессии
├── panel.py          # Обёртки над Remnawave: клиенты, HWID, трафик
├── remnawave.py      # Клиент API панели + экраны «Панель и узлы»
├── platega_api.py    # Клиент Platega: счета, возвраты (в т.ч. частичные)
├── webapi.py         # API личного кабинета (aiohttp)
├── site_deploy.py    # Деплой сайта и кабинета по SSH + страница кабинета
├── site_page.py      # Лендинг
├── blacklist.py      # Чёрный список: списки, остановки, автовозврат
├── winback.py        # «Возврат ушедших»
├── backup.py         # Бэкап и перенос
├── fraud.py          # Повторные триалы
├── staff.py          # Помощники и их права
├── maintenance.py    # Техработы и отключение функций
├── selftest.py       # Встроенные проверки бота
├── subscription.py   # Общая логика подписок
├── keyboards.py      # Общие клавиатуры
├── states.py         # Состояния ввода
├── log_channel.py    # Лог-канал
├── handlers/         # Хендлеры: start, user, admin, control, payments,
│                     #   callbacks, messages, tickets, support, broadcast…
├── paidsub/          # Платные подписки: экраны, клавиатуры, хранилище
├── adminsub/         # Админские подписки
├── docs/             # Политика конфиденциальности, оферта
├── assets/           # Логотип и OG-картинка сайта
├── scripts/          # notify_failure.sh — сторож сервиса
├── install.sh        # Установка на Ubuntu
└── README.md
```
